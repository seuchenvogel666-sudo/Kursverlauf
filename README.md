# Termine – Erinnerungs-App (Android)

## APK bauen
1. Android Studio installieren (https://developer.android.com/studio).
2. Diesen Ordner öffnen (File > Open). Die erste Synchronisierung lädt alles nötige herunter (Internet nötig, dauert einige Minuten).
3. Menü Build > Generate App Bundles or APKs > Generate APKs (bzw. "Build APK(s)").
4. Die Datei liegt danach unter app/build/outputs/apk/debug/app-debug.apk (Android Studio zeigt "locate" an).

## Aufs Handy
1. app-debug.apk aufs Handy kopieren (Kabel, Cloud, Messenger).
2. Antippen und installieren. Beim ersten Mal "Apps aus unbekannten Quellen" für den Dateimanager erlauben.
3. Beim ersten Start Benachrichtigungen erlauben. Für Sprachnachrichten die Mikrofon-Erlaubnis geben.
4. Widgets: Startbildschirm lange drücken > Widgets > "Termine": Nächster Termin / Nächste 3 / Nächste 5.

## Bedienung
- Karte nach rechts wischen: Verschieben (+1 Std., +1 Tag, eigenes Datum) oder Löschen, mit Rückgängig.
- Karte nach links wischen: Optionen (Wiederholung inkl. jährlich, Kategorie, Ton, Foto).
- + unten rechts: neuer Termin.
